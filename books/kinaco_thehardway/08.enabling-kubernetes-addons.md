## dnsプラグインを導入する

```
curl -L https://raw.githubusercontent.com/prabhatsharma/kubernetes-the-hard-way-aws/master/deployments/core-dns.yaml > core-dns.yaml
sed -i -E '/clusterIP/s/[0-9\.]+/172.20.0.10/' core-dns.yaml
sed -i -E '/kubernetes/s/local/internal/' core-dns.yaml
kubectl apply -f core-dns.yaml
```

          protocol: TCP

            - NET_BIND_SERVICE

            - all

            scheme: HTTP

### metrics server

clusterDNSが必要
cf: github.com/kubernetes-incubator/metrics-server.git
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml


```
curl -L https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml > metrics-server.yaml
kubectl apply -f metrics-server.yaml
kubectl top node
kubectl top pod
```
