### 前提条件

`apple/container` のネットワークを正しく設定するには、macOS 26 以降が必要です。以前のバージョンではコンテナ間通信ができません。

### Apple Container をインストールする

[apple/container](https://github.com/apple/container)の最新版（本記事執筆時点では0.5.0）を[ダウンロード](https://github.com/apple/container/releases/tag/0.5.0)し、インストールします。
インストール後、`apple/container`を起動します。初期状態だと、container VMはDNSドメイン`internal`に収容されます。

## 2. 仮想マシンを作成する

まず、systemdが動くコンテナイメージを準備します:
```shell:m4mac
cat >Dockerfile <<-EOF
  FROM debian:13.0-slim as systemd
  RUN DEBIAN_FRONTEND=noninteractive apt-get update \
      && apt-get install -y init systemd vim procps \
      && rm -rf /var/lib/apt/lists/*
  CMD ["/sbin/init"]
EOF
container build -t systemd -f Dockerfile
```

作成したイメージを使い、作業用1台、コントロールプレーン3台、ワーカー3台を起動します。
